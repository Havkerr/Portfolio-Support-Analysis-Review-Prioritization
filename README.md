# Portfolio Support Analysis & Review Prioritisation

An Excel-based financial services case study analysing **20 client portfolios and 98 investment holdings** to identify allocation differences and portfolios requiring review.

## Problem

Portfolio information is spread across client details, holdings, target allocations, and review schedules. Bringing these records together helps identify where follow-up is needed.

## What I Did

- Calculated total portfolio value and equity exposure using **SUMIF and SUMIFS**.
- Compared actual equity allocation with each client’s target allocation.
- Checked recorded review statuses for overdue reviews.
- Created a summary table to support portfolio review prioritisation.

## Key Findings

- Equity allocation differed from its target by approximately **20 percentage points** in the largest deviation.
- **Three portfolios** were marked overdue in the supplied review records.
- The summary makes allocation differences easier to compare across clients.

## Tools

Microsoft Excel — SUMIF, SUMIFS, percentage calculations, and summary tables.

## Project Files

| File | Contents |
|---|---|
| `clients.csv` | Client details, risk profiles, and relationship managers |
| `holdings.csv` | Investment holdings and market values |
| `target_allocations.csv` | Target asset allocations |

## How to Explore

Open `Portfolio_Sheet.xlsx` and start with the **Summary_Table** sheet. Use the other sheets to trace the calculations back to the source records.

## Outcome

The project brings portfolio values, equity exposure, and allocation differences into one view to support more focused review decisions.
